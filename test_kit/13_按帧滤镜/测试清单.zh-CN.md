# 按帧滤镜（振動 / 手ぶれ / ラスター / フレア / ノイズ）实机探针清单

## 背景

这次探针要弄清一件事：五种滤镜在不同帧率的工程里，是**按帧**变化，还是**按秒**变化。

做法：同一个白色圆（静止在画面中央），加同样的滤镜，分别放在 30 fps 和 60 fps 工程里导出，比较两边的效果。

「60换算」文件是 60 fps 工程，但滤镜里疑似按帧走的数值已经换算过（间隔、周期 ×2，速度 ÷2）。如果滤镜真的按帧走，换算版和 30 版在同一秒看起来应该一样；如果按秒走，换算版和 60 版应该一样。

## 〇、文件一览

所有文件都在本文件夹里：`D:\AviUtl Free Render FPS\test_kit\13_按帧滤镜\`

| 文件 | 说明 |
|---|---|
| `F_底稿_30.aup2` | 30 fps，圆，**无滤镜**（对照）。不要覆盖，只能「名前を付けて保存」 |
| `F_底稿_60.aup2` | 60 fps，圆，**无滤镜**（对照）。不要覆盖，只能「名前を付けて保存」 |
| `E1_振動_30.aup2` / `E1_振動_60.aup2` / `E1_振動_60换算.aup2` | 振動：滤镜对象，单独占一层（在白圆上方一层），作用于下方的白圆 |
| `E2_手ぶれ_30.aup2` / `E2_手ぶれ_60.aup2` / `E2_手ぶれ_60换算.aup2` | 手ぶれ：滤镜对象（カメラ制御 + 手ぶれ），单独占一层，作用于下方的白圆。白圆已补上 カメラ制御 目标对象的 Z=-40.00 设置 |
| `E3_ラスター_30.aup2` / `E3_ラスター_60.aup2` / `E3_ラスター_60换算.aup2` | ラスター |

| `截图\` | 设置对话框截图与异常截图 |

E1、E2、E4 的滤镜或生成对象各自是一层，层号比白圆小 1，时间范围与白圆相同。E3 的 ラスター 仍直接挂在白圆上。

每个 .aup2 导出为 `out\<同名>.mp4`，例如 `E1_振動_30.aup2` → `out\E1_振動_30.mp4`。

滤镜参数都已经写在文件里，**不要改任何参数**（包括 `_60换算` 文件，它们的数值已经换算好了）。

ノイズ 没有现成文件，要在界面里自己加，见第二节的 2.2。

## 一、准备

1. 确认 AviUtl2 是 v2.1.12（与其它清单一样）。
2. 在本文件夹里确认 `out\` 与 `截图\` 存在。不存在就新建空文件夹。
3. 全部是普通导出：输出插件选 x264guiEx，「Enable Free Render FPS」**不勾选**，不用 Free FPS Export。所以本次与插件版本无关。
4. 不要覆盖任何 .aup2。所有保存一律用「名前を付けて保存」。

---

## 二、步骤

### 2.1 文件表里的 14 个 .aup2

对每个 .aup2，按下面做一遍：

1. 打开该文件。
2. 预览：拖动时间轴或按播放，看圆上的滤镜效果是否可见、是否在动，记下动作（例如「抖动」「晃动」「条纹流动」「光晕闪烁」）。`F_底稿` 是对照，应该看不到任何滤镜效果。
3. 普通导出（见一、第 3 条），输出为 `out\<同名>.mp4`。
4. 关闭这个工程，**选择不保存**。

### 2.2 ノイズ（E5，手动做，两个帧率各一次）

仓库和用户工程里都没有现成的 ノイズ 写法，所以请在界面里加：

1. 打开 `F_底稿_30.aup2`。
2. 选中白色圆，给它加 ノイズ 滤镜。**参数保持默认，不要改**。
3. 打开 ノイズ 的参数对话框，截图存为 `截图\E5_ノイズ_30_设置.png`。把每一项的名字和默认值抄进回报。
4. 「名前を付けて保存」到 `out\E5_ノイズ_30.aup2`。
5. 预览，记下滤镜是否可见、是否在动。
6. 普通导出，输出为 `out\E5_ノイズ_30.mp4`。
7. 关闭，**选择不保存**。
8. 打开 `F_底稿_60.aup2`，重复第 2 至 7 步。文件名与截图分别为 `out\E5_ノイズ_60.aup2`、`out\E5_ノイズ_60.mp4`、`截图\E5_ノイズ_60_设置.png`。
   - 若 60 版的默认值和 30 版不同，照实记录，**不要改成一样**。

## 四、注意

- 打不开、报错、滤镜不见、圆不动，都截图存到 `截图\`，文件名写清楚，并照实记录。**不要改工程去凑结果**。
- 打开报错的文件，直接跳过，在回报里写明文件名与报错内容，然后继续下一项。
- 某一步做不下去，就在回报里写明停在哪一步，然后继续下一项。
- 界面上的文字以你的 AviUtl2 为准。这里写的日文名如果和界面不一样，照界面写并记录。
- 所有保存都用「名前を付けて保存」，不要覆盖底稿或其它 .aup2。
