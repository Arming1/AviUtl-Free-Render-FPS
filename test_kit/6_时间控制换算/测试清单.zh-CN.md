# 时间制御换算（Free FPS Export 1.2.2）早上测试清单

大白话版：先装测试版，再用 **Free FPS Export**（不是普通导出）导出几个工程，每个导出完跑一条分析命令，把结果发回来。

4. 安装包（x264guiEx-FreeRenderFPS.aux2，版本 1.2.2）的 SHA256：见本文件末尾。

7. 确认 `D:\AviUtl Free Render FPS\test_kit\6_时间控制换算\out\` 存在（已建好，里面是空的）。

注意：本轮只导出，不要保存工程。导出完关掉工程时选「不保存」，保持探针文件原样。

## 三、逐项说明

### 第 1 项：P7，30fps → 60

- **预期**：能导出。每 4 帧换一个位置（段长全是 4 帧）。
- **位置值**：和原 30fps 普通导出 `5_抽帧探针\out\P7.mp4` 的段值一致。也就是说，把两段的位置按时间顺序排列、去掉连续重复后，x 序列应该相同。
- **分析**（每个 mp4 各运行一次，不加 `--expect`）：

```
python -I "D:\AviUtl Free Render FPS\experiments\subscene_rate\analyze_steps.py" "D:\AviUtl Free Render FPS\test_kit\6_时间控制换算\out\P7_FreeFPS60.mp4"
python -I "D:\AviUtl Free Render FPS\experiments\subscene_rate\analyze_steps.py" "D:\AviUtl Free Render FPS\test_kit\5_抽帧探针\out\P7.mp4"
```

- **发回**：两个分析输出（段数、段长分布、前 10 段的「帧范围」「长度」「质心 x (px)」）；两者去重后的 x 序列是否一致。

### 第 2 项：P7，30fps → 66（应被拒绝）

- **预期**：不导出，弹出提示。コマ落ち=2，所以要求 2 × 66/30 = 4.4 为整数，不满足，应被拒绝。提示应包含 "multiple of 15/1"（建议帧率是「源帧率 / K」的倍数，即 15 的倍数；45 也是精确的，2 × 45/30 = 3）。照抄提示原文。
- **发回**：把提示的完整文字抄下来，截图存到 `D:\AviUtl Free Render FPS\test_kit\6_时间控制换算\截图\`（没有这个文件夹就新建）。
- 如果没有拒绝、而是生成了文件，告诉我文件路径。

### 第 3 项：P6（66fps，12 帧交替，rep1）→ 66 与 132

P6 工程的时间轴是 66fps，每个时间控制的「コマ落ち」是 1。12 帧一块，每块内是一次 0→全程 或 全程→0 的扫动。

- **目标 66（3a）**：
  - 预期：能导出。66 是原帧率（k=1），每块 12 帧，每块内仍是一次扫动。与原生导出 `out\P6_原生_rep1.mp4` 逐帧一致（质心差 < 0.5 px）。
  - **注意**：「コマ落ち」为 1（不丢帧）时不乘倍数、不受整数倍限制，所以这一项应当能导出。如果仍然被拒绝（被其他规则拒绝），把提示原文抄下来，并截图存到 `截图\`，照实记录即可。
- **目标 132（3b）**：
  - 预期：能导出。132 是 66 的 2 倍，每块 24 帧（12 × 132/66），每块内一次 0→全程 或 全程→0 扫动，按秒与原视频对齐。
- **原生对照**：普通导出（「Enable Free Render FPS」不勾选，输出插件选 x264guiEx）同一工程，文件名 `D:\AviUtl Free Render FPS\test_kit\6_时间控制换算\out\P6_原生_rep1.mp4`。用来与 66 逐帧对比，与 132 按秒对齐。
- **分析**（每个 mp4 各运行一次，不加 `--expect`）：

```
python -I "D:\AviUtl Free Render FPS\experiments\subscene_rate\analyze_steps.py" "D:\AviUtl Free Render FPS\test_kit\6_时间控制换算\out\P6_FreeFPS66.mp4"
python -I "D:\AviUtl Free Render FPS\experiments\subscene_rate\analyze_steps.py" "D:\AviUtl Free Render FPS\test_kit\6_时间控制换算\out\P6_FreeFPS132.mp4"
python -I "D:\AviUtl Free Render FPS\experiments\subscene_rate\analyze_steps.py" "D:\AviUtl Free Render FPS\test_kit\6_时间控制换算\out\P6_原生_rep1.mp4"
```

- **发回**：每个 mp4 的段数、段长分布、前 10 段；3a 与 `P6_原生_rep1.mp4` 逐帧的质心差（最大值，px）；3a 或 3b 是否被拒绝（若拒绝，提示原文）；每块是否仍是一次扫动（肉眼确认）。

### 第 5 项：ARZ 模板副本，66fps → 132（主测）与 66（对照）

- 这个工程是 `D:\ARZv2.0.1\ARZv2.0.1\template\15_mer1\.aup2` 的副本（只复制，原件没有动）。工程帧率 66。
