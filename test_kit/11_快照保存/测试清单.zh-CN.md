# 快照保存探针 实机测试清单

## 一、要回答的问题

用菜单 **编辑 > Snapshot Save Probe** 把当前工程存到另一个文件（`%TEMP%\SnapshotSaveProbe\snapshot.aup2`）之后：

1. 当前工程的路径变没变？
2. 保存回调（工程保存时的回调）触发了没有？
3. 标题栏的 `*`（未保存）还在不在？标题有没有变成 snapshot 的路径？
4. 之后按 Ctrl+S，是弹「另存为」，还是直接存到了 snapshot 路径？

## 二、步骤

### 0. 准备

1. 关闭 AviUtl2。
2. 右键 `安装.ps1` > 使用 PowerShell 运行。同意 UAC 提升。看到「安装成功，SHA-256 一致」后按回车。
3. 启动 `D:\aviutl2 v2.1.12\aviutl2.exe`。

### 情况 A：新建工程（不保存）

1. 「文件 > 新規作成」新建一个工程。**不要保存**。
2. 随便加一个对象（文字、图形都行）。标题栏应出现 `*`。
3. 点「编辑 > Snapshot Save Probe」。
4. 弹窗出来后，**截图**（整个弹窗内容）。
5. 点弹窗的确定。看标题栏：`*` 还在吗？标题变成 snapshot 路径了吗？
6. 按 **Ctrl+S**。看结果：
   - 弹出「另存为」对话框：记下，然后点取消。
   - 直接存了，没弹对话框：记下标题栏显示的路径。

### 情况 B：打开一个已保存的工程

1. 把 `test_kit\10_次合成对齐\P1_对齐.aup2` 复制一份，副本放在 `test_kit\11_快照保存\P1_副本.aup2`。**不要改原件**。
2. 「文件 > 開く」打开 `P1_副本.aup2`。
3. 改动一处（比如移动一个对象）。标题栏应出现 `*`。
4. 点「编辑 > Snapshot Save Probe」。**截图**弹窗。
5. 点确定。看标题栏：`*` 还在吗？标题有没有变？
6. 按 **Ctrl+S**。看保存到哪里。应该是副本本身（`P1_副本.aup2`）。如果弹了「另存为」或者存到了 snapshot 路径，记下。

### 结束

1. 关闭 AviUtl2。
2. 把 `%TEMP%\SnapshotSaveProbe\result.txt` 的内容发给我（`%TEMP%` 在资源管理器地址栏输入即可）。
3. 运行 `卸载.ps1`（右键 > 使用 PowerShell 运行）。

## 三、注意

- 每点一次探针，弹窗内容都会追加到 `result.txt`。
- 如果弹窗里的「save 回调次数」大于 1，可能是自动备份也在同一时间触发了保存。照实记下即可。
- 探针只做这一件事：不打开工程，不导出。
