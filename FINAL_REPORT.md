# AviUtl2 FreeRenderFPS v1.0.0 final report

Date: 2026-08-13  
Decision: **v1.0.0 release gates passed**

## Outcome

FreeRenderFPS now ships a Release x64 AUO2 that identifies as `1.0.0`, an
audited x264/FFmpeg/L-SMASH runtime, a one-click console installer, and a
direct-extract portable ZIP. RC1 remains frozen and was not overwritten.

The complete requested FPS matrix passed. In the 30 → 60 and 66 → 60 tests,
all 300 decoded output frames were unique, proving real intermediate timeline
evaluation rather than copied frames or metadata-only FPS changes. FreeFPS OFF
also preserves the normal integer-frame output path.

## Provenance policy

`third_party/sources.lock.json` locks exact source archives/commits, source
hashes, patches, build script, toolchains, options, and license mode.
`third_party/manifests/THIRD_PARTY_RELEASE_ARTIFACTS.json` separately locks the
specific binaries selected for this release. x264 is byte-reproducible across
two clean roots. FFmpeg and L-SMASH are provenance-locked but are not falsely
claimed to be byte-identical across arbitrary build paths.

## Package validation

- Installer self-test: install, upgrade, backup, rollback, uninstall and hash
  validation passed.
- Final setup package: fresh isolated host, exactly one AUO2, real H.264/AAC
  encode, 150 frames at 30 FPS, 5.000000 s audio/video.
- Final portable package: direct extraction creates
  `data\Plugin\x264guiEx-FreeRenderFPS`; the same real encode passed.
- Package scans found no PDB, Debug, probe, watcher or breakpoint artifacts.
